요약

노출계는 계정이 없고, 광고·분석 도구를 쓰지 않으며, 개발자가 어떤 개인정보도 받거나 저장하지 않습니다.

카메라

화면에 보이는 장면의 밝기를 재서 노출값을 계산하는 데만 씁니다. 사진이나 영상은 저장하거나 기기 밖으로 보내지 않습니다.

위치

  • 지금 있는 곳의 하늘(위성 일사량)로 노출을 계산하려고 대략적인 위치를 씁니다. 위치 허용을 하지 않으면 서울 기준으로 계산합니다.
  • 예보·예비 위성 값을 받을 때 약 5km 단위로 뭉갠 좌표를 Open-Meteo(open-meteo.com)에 보냅니다. 천리안 위성 자료를 받을 때는 위치를 보내지 않습니다.
  • 위치의 동 이름("서교동" 등)은 Apple의 지도 서비스로 조회합니다.
  • 위치는 개발자에게 오지 않으며, 계산이 끝나면 기기에도 따로 기록하지 않습니다(마지막 계산 값과 동 이름만 기기 안에 잠깐 기억합니다).

기기 안에만 저장하는 것

필름 감도·장면 같은 설정과 최근 날씨 계산 값. 앱을 지우면 함께 지워집니다.

외부 서비스

  • GitHub(github.io·githubusercontent.com): 천리안 위성 자료 파일을 받아오는 곳입니다. 요청 시 일반적인 접속 기록(IP 주소 등)이 GitHub 서버에 남을 수 있습니다.
  • Open-Meteo: 예보·예비 위성 값. 위와 같이 대략적인 좌표가 전달됩니다.
  • Apple: 위치 확인, 동 이름 조회.
